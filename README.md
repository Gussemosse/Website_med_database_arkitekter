# Webserver med database af bygninger og arkitekter ved søgning

## Nødvendige biblioteker
Disse biblioteker bliver brugt i programmet, og skal installeres for korrekt brug af programmet (eventuelt ved brug af et virtual environment):

- flask
- sqlite3
- base64

```pip install flask sqlite3 base64```

## VSC Extensions (ikke nødtvendigt)
For at kunne tilgå databasen og dermed kigge på alle arkitekter og bygninger og deres værdier, forslår jeg at installere denne udvidelse/extension:

- SQLite3 Editor

Denne udvidelse skaber et smukt og overskueligt syn over rækker og værdier i databasen.
